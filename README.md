📝 Project Title:
Interactive Salary Prediction Dashboard using IBM BOB
📄 Project Description:
This project is an Interactive Salary Prediction Dashboard built leveraging the advanced capabilities of the IBM BOB agent environment. The core purpose of this application is to analyze and predict employee salaries based on their years of experience using a data-driven approach.
The backend intelligence relies on a Linear Regression Machine Learning Model trained on a standard 30-record dataset (Salary_Data.csv). The model successfully established a high-accuracy mathematical relationship with an outstanding R² Score of 0.9570 (indicating a 95.7% accuracy rate in capturing variance).
Mathematical Foundation Applied:
• Formula: Salary = (9449.96 × Years of Experience) + 25792.20
• Average Prediction Error: ± $4,644.20
🚀 Key Features Implemented:
• Real-time Live Prediction: Users can enter any number for "Years of Experience" and instantly get the calculated predicted salary alongside a statistically safe lower and upper performance boundary range.
• Dual Data Visualizations: Integrated dynamic graphs utilizing Chart.js:
	• Bar Chart: Visually demonstrates the actual earnings across all 30 employee milestones.
	• Scatter Plot with Trend Line: Plots empirical data nodes natively alongside the computational regression model line.
• Analytical Data Table: A breakdown layout showing real-time error percentage tracking against original actual data variables.
• Premium VS Code Dark Theme UI: Designed entirely in a responsive, modern glassmorphic layout tailored specifically to align with high-end IDE work ecosystems.
